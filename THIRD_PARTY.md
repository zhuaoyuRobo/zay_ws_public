# Third-party software

This workspace vendors several upstream ROS packages, including FAST-LIO,
Livox ROS Driver 2, lidar localization components, NDT registration, and robot
description resources. Their source directories contain the authoritative
copyright and license notices.

Before redistribution, review every package manifest and license file. The
Apache-2.0 declaration of `isaac_go2_nav2` does not relicense third-party code.
